# Readora iPhone 版

当前 0.6.0 build34（2026-10-26），最低 iOS17。手机版与 Mac 的功能对齐范围、验证和平台限制见 [功能对齐说明](../parity/README.md)。

## 安装

1. 数据线连接并解锁 iPhone，在手机上信任此电脑。
2. Xcode打开根目录 `Readora.xcodeproj`，选择 **ReadoraiOS** scheme和真实iPhone。
3. Signing & Capabilities选择自己的Team并保持自动签名，按⌘R安装。按系统提示启用开发者模式。

本机开发签名 Debug 包位于 `.build/kokoro-ios/Build/Products/Debug-iphoneos/Readora.app`。使用轻量 Kokoro，资源约 198 MB，保留 15 音色与双语混读；朗读设置支持本地多音字词典。旧 Qwen、Melo、系统声音已移除。安装与启动结果见下方本轮验证记录。开发签名包不是公开分发 IPA。

```sh
python3 -m pip install onnx==1.20.1 numpy==2.5.4
python3 scripts/prepare-kokoro.py

xcodebuild -project Readora.xcodeproj -scheme ReadoraiOS -configuration Release -destination 'generic/platform=iOS' -derivedDataPath .build/ios-device -clonedSourcePackagesDirPath .build/kokoro-packages -allowProvisioningUpdates build
```

朗读控件收起为悬浮球，点击展开；手机可上下拖动。阅读菜单提供音色/速度设置、选中文字高亮、目录与标记。书库菜单提供列表/网格、书架、回收站、最近朗读及设置。设置中可启用手机MCP，复制带独立令牌的HTTP配置；请在可信局域网使用且保持App前台。

手机与Mac书库独立，未实现云同步；导入原文件保持不变。模型密钥保存于本机钥匙串；localhost指手机自身。首次语音聊天请求麦克风及语音识别权限，MCP请求本地网络权限。真机听感、长时间播放、录音及局域网MCP仍需验收。
