# 17 · 测试策略

## 测试层级与责任

| 层级 | 覆盖重点 | 执行时机与证据 |
|---|---|---|
| 领域单元 | 锚点编解码、UTF-16/emoji、分句、去重、进度策略、tombstone、分叉 revision | 每 PR；确定性时钟和 UUID 注入 |
| 引擎合同 | 三格式 open/navigate/search/close、能力禁用、取消与旧回调 | 每引擎修改；同一合同样例 + 格式特例 |
| 集成 | 文件 journal、Core Data 事务、迁移、索引、DOM 映射 | 每 PR 相关集；临时目录/SQLite，不能只用内存 store |
| 状态机 | 播放/暂停/seek/换章/音频中断/错误恢复 | fake SpeechEngine 乱序事件、generation 检查 |
| UI | 导入→阅读→设置→书签→朗读→恢复；键盘与 VoiceOver | 两平台 nightly；P0 流程每 RC |
| 真机音频 | 锁屏、蓝牙、耳机、来电、静音键、低电量、进后台 | iPhone 最低/最新系统；2小时会话录像与时间线 |
| 云端 | 两设备离线编辑、账户切换、配额不足、元数据先到 | 专用测试账户与开发容器；TestFlight 生产环境另测 |
| 性能/安全 | 大书、内存、卡顿、恶意包、桥接输入 | nightly/RC；Release 构建、固定夹具 |

## 夹具清单

30 本 MVP、100 本 V1 基准库：自制中文/英文/混合 EPUB，emoji/组合附标/长句/脚注/嵌套目录/缺封面/超大图片；PDF 文本/扫描/多栏/旋转/密码/权限；TXT 多编码/单长段/跨块 surrogate；zip slip、symlink、外部实体、远程资源、脚本攻击。每本登记生成方法、许可证、hash、期望目录、锚点和预期能力，禁止将未授权商用书入仓。

## 必要的确定性测试

- 同一文本 UTF-16 offset → DOM/TextKit → offset 往返一致，字体与视口变更后 quote 不变。
- import 在复制、rename、数据库提交前后逐点注入失败，重启无孤儿记录、无丢原文。
- state machine 生成操作序列，stop 后旧 generation 的 finish/range 不影响 UI。
- 断网双端从相同 baseRevision 编辑，联网后两个版本均可见，合并可重复执行且幂等。
- 旧版 payload/数据库升级后 bookmarks 与 notes 可定位；迁移失败保留原库且支持导出。
- 手动滚动后 100 个语音事件不触发自动回拉；明确恢复跟随后只按新句更新。

## 自动化命令合同

工程创建后先 `xcodebuild -list -project Readora.xcodeproj` 获取真实 scheme，不能把下列示意命令当作本轮已执行：

```sh
xcodebuild test -project Readora.xcodeproj -scheme ReadoraMac -destination 'platform=macOS'
xcodebuild test -project Readora.xcodeproj -scheme ReadoraiOS -destination 'platform=iOS Simulator,id=<CI_SIMULATOR_UDID>'
```

CI 固定 Xcode、模拟器 UDID 与系统镜像；纯算法 suite 可用 Swift Testing，UI/性能使用 XCTest。测试不得请求用户真实书库或生产 iCloud 容器。同步真机测试无法由模拟器结果替代。

## 发布门槛

P0 用例全部通过、无未处理崩溃/数据丢失；P1 缺陷有责任人和明确版本处理计划。性能预算超标须说明设备、场景和用户影响，再决定优化或缩小支持范围，不静默改验收。

100 次重开与跨字号恢复至少 99.5% 命中需扩大到 ≥1,000 次定位样本才有细粒度统计意义；报告样本量和失败原文锚点，不能用一次演示证明可靠率。后台锁屏连续朗读、无障碍完整闭环和双设备冲突各保留人工签核。

本轮仅验证文档结构、链接与示例合同；没有应用可运行，因此没有通过任何应用单元测试、性能测试、CloudKit 或真机音频验证。
