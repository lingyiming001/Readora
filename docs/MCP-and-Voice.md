# MCP 外部控制与语音聊天（0.6.0）

## 连接其他 AI 产品

1. 打开新版 Readora，进入设置 → MCP，选择端口并启用本机服务。
2. 点击“复制 MCP 连接配置”，将 JSON 合并到支持 **stdio MCP** 的 AI 产品的 MCP 配置中。不同产品的配置入口与文件位置各自不同。
3. 在对应 AI 产品中重新连接 Readora，先查询书库，再描述想做的操作，例如“新建一个英语学习书架”或“把 Readora 改成夜间主题”。

连接配置引用应用包内的 `Contents/MacOS/ReadoraMCP`，不依赖 Python、Node 或另行安装的运行时。移动应用包后须重新复制配置。Readora 应用必须保持打开，服务每次启动默认关闭。使用自定义端口后也须重新复制配置。

MCP 子进程通过标准输入/输出传输换行分隔的 JSON-RPC，支持 initialize、ping、tools/list 和 tools/call；协商支持 2024-11-05、2025-03-26、2025-06-18，未知版本返回支持的版本。公开一个 readora 工具，其 action 参数与应用内 AI 的白名单操作一致。桥接进程通过仅绑定 127.0.0.1 的内部 HTTP 端点与应用通信；内部 `/rpc` 不是公共 Streamable HTTP MCP 接口，远程云端仅接收 URL 的连接器无法直接使用。

客户端环境变量为 `READORA_MCP_TOKEN` 和 `READORA_MCP_PORT`，均由设置自动生成配置。连接令牌保存在当前用户的应用偏好中，供重开应用后继续使用；它不是大模型 API Key。不要分享连接配置。重置令牌会撤销旧配置；关闭服务会拒绝待确认操作并断开连接。桥接进程拒绝 HTTP 重定向，不使用系统代理。

## 操作与确认

外部 AI 可查询书籍、书架、标记、音色和模型，创建/重命名书架、修改书架归属、主题/字体/朗读/导入配置、导航及控制阅读。导入仍需用户在系统选择器中选文件，服务不提供任意文件读取、系统命令、访问 API Key 或控制其他应用。

移入回收站、永久删除、清空回收站、删除书架/模型、移除标记和清除朗读历史，都会在 Readora 窗口显示实际对象与影响，等待用户确认；120秒未确认自动拒绝。外部 AI 不能替用户点击确认。请保持 Readora 窗口可见，必要时调高 AI 客户端的工具调用超时到150秒以上。等待确认期间其他外部操作返回忙碌，不会并发执行；拒绝不会修改对象。

清空回收站绑定确认时的清单，不顺带删除后来移入的书。永久删除只删除应用内副本，保留导入源文件。MCP 返回实际执行结果；打开书籍和翻页可能先返回已请求，客户端应查询 state 确认加载状态，不能假定已完成。

内部端点检查连接令牌，拒绝浏览器 Origin、重复头、Transfer-Encoding 和不合法长度；请求上限64KiB、头部8KiB、最多8条连接，接收请求10秒超时。stdio 同样限制单条消息大小。它是本机用户主动授予的应用操作能力；系统中的同用户程序能读取偏好或客户端配置，不构成跨用户安全隔离。

## 语音聊天

1. 在 AI 设置中配置并启用模型。
2. 打开 AI 助手，点击“语音聊天”，选择中文或 English，点击“开始说话”。首次使用由 macOS 请求麦克风和语音识别授权。
3. 点击“结束录音并识别”，或等待每次最多45秒结束。开启“识别完成后自动发送”时，识别完成即提交；关闭后可先编辑文本再点击发送。
4. “朗读 AI 回答”使用已选系统音色和正常聊天语速；“打断回答”可停止声音。再次开始说话会停止旧回答和书籍朗读，避免把播放声音录进去。
5. 同一个面板保留最近至多8轮、24000字符的对话；点击“新对话”清空。切换路由模型也会清空；关闭面板后不持久化聊天。

优先使用 Apple 设备端识别；不支持时可能使用 Apple 语音服务。识别文本、当前引用和保留的对话会发送给所选大模型。应用不保存麦克风音频，不在后台持续监听。权限拒绝、没有麦克风、识别不可用或请求失败时可使用文字输入，错误不会伪装成成功。

语音入口用于多轮问答、翻译和词义解释，采用逐次说话、回答的交互。应用操作使用单独“操作应用”模式；语音聊天不会自动执行识别出的删除或配置命令。当前未接供应商原生 Realtime 音频、声纹、唤醒词或全双工打断检测。

## 验证边界

63项无界面单元测试通过；最后调整后2项MCP服务定向测试再次通过，打包的桥接程序通过保持stdin打开时的握手/通知/工具发现/调用/EOF检查，应用签名及语音权限声明通过检查。曾发现Foundation管道读取等待填满缓冲区，已改为POSIX即时读取并回归通过。自动验证仅使用模拟协议请求及隔离本机传输，不使用正式书库、真实模型、麦克风或界面。首次授权、真实识别与扬声器效果、各 AI 客户端实际兼容性需由用户手动验证。
