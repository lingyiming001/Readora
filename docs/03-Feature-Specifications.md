# 03 · 功能规格与验收标准

各功能 ID 是任务与测试的关联键。P0 为当前版本阻断，P1 为该版本必要增强，P2 为后续候选。

| ID / 阶段 | 输入与行为 | 验收与错误分支 |
|---|---|---|
| LIB-01 / MVP P0 | 选择或拖入 EPUB/PDF/TXT，复制进沙盒 | 取消无残留；失败可重试；拒绝扩展名伪装、损坏包、超限；导入不移动原文件 |
| LIB-02 / MVP P0 | SHA-256 检测字节重复，优先返回既有书 | 两次同文件只有一本可见记录；不同内容同标题保留两本；并行重复提交也去重 |
| LIB-03 / MVP P0 | 封面网格/列表，标题作者过滤，最近/标题排序 | 1,000 本分页获取；无封面有可读占位；过滤无结果可清除 |
| LIB-04 / V1 P1 | 收藏、标签、手动书架、阅读状态、归档、批量移动 | 批量中失败逐项展示；归档不删文件；书架删除保留书籍 |
| LIB-05 / MVP P0 | 移入回收站、恢复、30 天后可清理 | 删除正在听的书先停止；彻底删除二次确认；恢复保留笔记关联 |
| LIB-06 / V1 P1 | 缺失文件修复、导出原文、阅读历史和统计 | hash 不一致新建版本；导出失败可重试；统计不包含锁屏静置 |
| IMP-02 / V1.1 P1 | 分享扩展落共享 inbox，主应用接续导入 | 扩展不做完整解析；重复请求幂等；App Group 权限缺失明确报错 |
| READ-01 / MVP P0 | 打开三个支持格式、目录导航、关闭重开 | 回到同一正文锚点；布局变化不退回首页；失败进入修复页 |
| READ-02 / MVP P0 | EPUB/TXT 字体字号、行段距、页边距、主题 | 连续改设置只应用最终版本；不支持的格式控件隐藏并说明 |
| READ-03 / MVP P0 | 选择复制、书签创建删除 | 书签跳转命中原句；不可复制的 PDF 尊重文档限制 |
| READ-04 / V1 P0 | 高亮、附注、笔记列表、编辑删除、导出 | 更换字号高亮仍定位；跨资源选择拆成多段；失效定位可人工修复 |
| READ-05 / V1 P1 | 全文搜索、结果摘要、点击跳转 | 索引未完成可取消；命中映射原文；扫描 PDF 显示不可搜索 |
| READ-06 / V1.1 P1 | 横向分页、双页、动画 | 旋转/缩放不丢锚点；Reduced Motion 关闭大幅动画；分页失败可回滚动 |
| TTS-01 / MVP P0 | 从当前段落起播、暂停/继续/停止、声音速率 | 冷重启显示恢复按钮，点击后从最近持久化句首开始；不自动出声 |
| TTS-02 / V1 P0 | 上下句/段/章、点击选中文字起播、连续章播放 | 边界按钮正确禁用；快连点不出现旧队列发声；空章自动跳过 |
| TTS-03 / V1 P0 | 句高亮、自动跟随、手动滚动暂停跟随 | 手动浏览不被拉回；点击恢复跟随；旧章节回调不能染色新章节 |
| TTS-04 / V1 P0 | iPhone 后台、锁屏/耳机、媒体控制、音频中断 | 真实设备 2 小时连续测试；拔耳机暂停；来电后仅按用户意图及系统许可恢复 |
| TTS-05 / V1 P1 | 语言检测、声音匹配、睡眠定时、快捷设置 | 未安装声音有回退提示；15/30/60 分钟和章末停止；后台到期也停止 |
| SYNC-01 / V1 P0 | 可选元数据同步、离线修改、远端位置提示 | 双设备断网冲突不丢笔记；活动会话不跳转；未登录不阻塞本地 |
| SYNC-02 / V1.1 P1 | 用户选择原始文件同步、下载、容量与错误提示 | 文件先暂存后校验；元数据先到也可恢复；空间不足保留本地 |
| DATA-01 / MVP P0 | 原文/元数据备份导出与本地恢复 | 在空库恢复后数量、hash、位置一致；覆盖前预览；格式版本不兼容拒绝 |
| A11Y-01 / 各阶段 P0 | VoiceOver、键盘、Dynamic Type、对比度 | 全闭环无鼠标或无视觉可完成；控制器焦点与朗读高亮互不抢占 |

## 通用状态合同

列表必须覆盖 empty/loading/content/error/offline；导入任务为 queued/copying/validating/parsing/committing/succeeded/failed/cancelled。取消发生在提交前清理暂存，提交后提示已完成而非虚假取消。错误统一包含稳定 code、中文解释、可执行恢复动作、脱敏诊断 ID。

## 端到端验收脚本

给定新装应用和本地 EPUB，导入 → 搜索 → 打开 → 改字号 → 加书签 → 读到第二章 → 开始朗读 → 暂停 → 继续 → 返回书库 → 重开书 → 退出应用 → 再启动。结果：书库仅一条、阅读锚点不丢、朗读不自动播放、点恢复从检查点句首起播。PDF/TXT 重复同脚本，按能力表跳过不可重排或无文本能力；禁用原因必须可见。

V1 追加断网两端各修改笔记、恢复联网、选择远端位置、锁屏耳机控制及高亮跟随。所有 P0 通过才允许进入对应版本候选。
