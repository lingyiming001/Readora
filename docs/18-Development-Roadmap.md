## 依赖链与范围控制

模型/定位 → 导入/原文 → 阅读/恢复 → 内容分句 → TTS → 跟随/后台 → 批注/冲突 → 同步 → 公开发布。设计阶段可与探针局部交错，但读取位置、文本规范化与同步标识不得由各引擎独立发明。

阶段 7 的 MVP 必须完整验证「导入、管理、阅读、设置、保存、朗读、暂停继续、退出恢复、重开」。V1 的完善书库与全文搜索不能挤掉这个闭环。每阶段交付包含实现、测试、错误恢复说明和文档更新；未达验收不得仅凭页面完成度通过。

## V1.1 和未来

V1.1：分享扩展、原文 iCloud Drive 同步、横翻/双页与动画；先验证 App Group inbox 与文件同步补偿。Later：iPad 分栏/键盘/分屏、OCR、AI TTS、Markdown/HTML/FB2。Markdown/HTML 可转安全规范文本；FB2 需 XML 映射；MOBI 因复杂版本、许可和 DRM 边界暂不承诺，建议用户合法转换为 EPUB。扩展格式每项必须重复位置/文本提取/许可评审。
